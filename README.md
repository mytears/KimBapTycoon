# 별밤분식

밤 골목의 작은 분식집을 운영하는 세로형 타이쿤 게임입니다. 웹과 Android가 같은 HTML, CSS, JavaScript와 그림을 사용합니다.

## 웹에서 실행

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 개발용 서버는 프로젝트 폴더에서 다음 명령으로 실행한 뒤 `http://127.0.0.1:4317`에 접속합니다.

```sh
python -m http.server 4317 --bind 127.0.0.1
```

## 게임 흐름

1. 자금 10,000원으로 시작합니다. 손님의 주문을 읽고 김밥, 떡볶이, 라면 중 하나를 선택합니다.
2. **조리 시작**을 누르고 음식이 완성되면 **손님에게 건네기**를 누릅니다. 판매 대금이 바로 들어옵니다.
3. **가게 관리**에서 조리 시간을 줄이거나 메뉴 판매가를 올릴 수 있습니다. 2호점부터는 하루 정산 때 분점당 5,000원의 수익을 받습니다. 최대 5호점까지 운영합니다.
4. 주문 8건을 마치면 하루를 정산합니다. **영업 일지**에서 지난 매출을 확인할 수 있습니다.

진행 상황은 기기의 브라우저 또는 앱에 자동 저장됩니다. 조리 중 닫아도 완료 시간이 유지됩니다. 웹과 Android 앱의 저장 공간은 별개입니다.

## Android 빌드

Android Studio에서 `android` 폴더를 열거나, JDK 17 이상과 Android SDK 35가 설치된 환경에서 실행합니다.

```powershell
cd android
.\gradlew.bat assembleDebug
```

설치용 테스트 APK는 `android/app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. 웹 소스와 이미지는 빌드 시 복사되므로 한 곳에서 수정할 수 있습니다. 앱은 게임 파일을 내장하여 오프라인에서도 실행됩니다.

## 구성

- `index.html`, `style.css` — 세로형 게임 화면과 반응형 배치
- `game.js` — 주문, 조리, 가게 개선, 분점 수익, 정산과 저장
- `assets/` — 가게 배경, 음식과 손님 도트 그림, Galmuri 글꼴과 배포 라이선스
- `android/` — 세로 화면 WebView 앱과 Gradle 빌드 프로젝트

가게 배경(`assets/shop.webp`)은 내장 이미지 생성 도구로 제작했습니다. 그림의 기준은 ‘짙은 보랏빛 밤 골목, 붉은 줄무늬 차양과 별밤분식 간판, 김이 오르는 조리대 뒤의 주인과 곁에서 잠든 고양이를 정면에서 바라본 16비트 도트 풍경’입니다.
