# 별밤분식

밤 골목의 작은 분식집을 운영하는 타이쿤 게임입니다. PC에서는 대기 주문과 조리대를 나란히 보고, 휴대전화에서는 세로 화면으로 플레이합니다. 웹과 Android가 같은 게임과 그림을 사용합니다.

## 웹에서 실행

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 개발용 서버는 프로젝트 폴더에서 다음 명령으로 실행한 뒤 `http://127.0.0.1:4317`에 접속합니다.

```sh
python -m http.server 4317 --bind 127.0.0.1
```

## 게임 흐름

1. 자금 10,000원으로 시작합니다. 영업시간은 **07:00~22:00**이고, 하루는 플레이 시간 3분입니다. 아침 7시, 점심 11시, 저녁 17시, 밤 20시에 골목의 빛이 바뀝니다. 날마다 한산하거나 붐비는 정도가 달라지고, 12종의 손님이 불규칙한 간격으로 찾아옵니다. 점심과 저녁 식사 시간에는 입장 간격이 짧아집니다. 매장에는 최대 다섯 명이 기다립니다.
2. 대기 주문을 보고 **빈 조리대의 메뉴 선택**을 누르세요. 열린 목록에서 음식을 누르면 그 조리대의 첫 단계가 시작됩니다. 야채김밥은 밥을 편 뒤 **속재료 올리기 → 말아서 썰기**를 누릅니다. 완성되면 **손님에게 건네기**를 눌러 주문순으로 판매하세요. 메뉴판에서 아홉 음식의 판매가와 레시피를 확인할 수 있습니다.
3. 대기 시간은 각 손님이 들어온 순간부터 흐릅니다. 성미 급한 손님은 30초, 보통 손님은 40초, 느긋한 손님은 50초를 기다립니다. 메뉴 선택 창에도 현재 주문의 남은 시간이 표시됩니다. 시간이 다 되면 손님은 1점을 남기고 떠나며, 그 주문으로 만들던 음식도 사라집니다.
4. 기본 조리 시간은 단계당 2.5초입니다. **가게 관리**에서 조리 장비를 처음 개선하면 조리대가 두 대가 되어 앞선 두 주문을 동시에 준비할 수 있습니다. 두 번째 음식이 먼저 완성되면 해당 조리대에서 서빙 차례를 기다립니다. 장비는 스테인리스 2구 레인지, 황동 조리 스테이션 순으로 바뀌고 업그레이드마다 각 단계가 0.25초 짧아집니다. 30,000원으로 직원 한 명을 채용하면 모든 조리대의 단계당 시간이 추가로 0.5초 줄어듭니다. 메뉴 연구는 판매가를 올립니다.
5. **조리 시작 후 12초**가 되면 완성된 음식도 탑니다. 조리대에서 남은 시간을 확인하세요. 탄 음식을 내면 손님이 화를 내고 1점을 남기며 대금은 0원입니다. 다시 조리하면 조리 시간은 새로 시작하지만 손님의 대기 시간은 계속 흐릅니다.
6. 주문 접수 후 10초 이내에 정상 음식을 내면 5점, 그 이후에는 3·4·5점 중 하나를 기본 평점으로 받습니다. 상단의 별은 전체 손님 평가의 평균입니다. 밤 10시에 영업을 마치며 남은 주문은 마감 미제공으로 집계합니다. **영업 일지**와 정산에서 그날의 평가, 판매, 탄 음식, 시간 초과와 매출을 확인할 수 있습니다.
7. 모든 메뉴의 두 번째 조리 단계에 노란 구간이 있습니다. 표시가 구간에 오면 **속재료 정돈**, **만두 뒤집기**처럼 음식에 맞는 버튼을 누르세요. 성공하면 즉시 3단계 버튼이 열리고, 완성한 음식을 서빙하면 팁 500원을 받습니다. 타이밍을 놓친 음식도 기본 판매가로 판매할 수 있습니다.
8. 가게 이름 아래 강조된 **오늘 목표**와 진행도를 확인하세요. 바삭한 군만두 한 접시 판매, 점심(11~14시) 주문 두 건 판매, 10초 이내 서빙 세 건이 하루에 하나씩 돌아옵니다. 목표를 달성하면 확인 창이 뜨고 마감 정산 때 3,000원을 받습니다.
9. **메뉴 연구**는 최대 6레벨이며 레벨마다 모든 메뉴의 판매가를 500원 올립니다. **동네 홍보**는 레벨마다 기본 입장 간격을 10%씩 줄이고, **서비스 개선**은 레벨마다 정상 음식 평점에 0.2점을 더합니다. 홍보와 서비스 개선은 각각 최대 3레벨입니다. 평점은 최대 5점이고 탄 음식은 1점입니다.
10. **업적** 메뉴에서 누적 업적 30개의 타이틀과 진행도를 확인할 수 있습니다. 라면 200그릇을 판매하면 **라면의 달인**, 별점 5점을 100번 받으면 **별 다섯 맛집**을 달성합니다. 목표나 업적을 달성하면 확인 창을 닫을 때까지 손님 대기와 조리 시간이 멈춥니다. 저장된 메뉴별 판매량과 영업 기록은 확장된 업적에도 반영됩니다.
11. **가게 관리 → 가게 꾸미기**에서 차양과 간판을 조합해 미리 볼 수 있습니다. 쑥빛 차양은 4,000원, 쪽빛 차양은 6,000원, 청록 법랑 간판은 5,000원, 달빛 네온 간판은 9,000원입니다. 적용할 때 새로 고른 장식 값만 결제하고, 구입한 장식은 자유롭게 바꿔 쓸 수 있습니다. 달성한 업적 칭호 하나를 골라 가게 앞 명패에 무료로 걸 수 있습니다.

영업 중에는 손님 줄과 남은 시간, 진행 중인 조리 단계가 자동 저장됩니다. 조리대의 메뉴 선택 창을 열어 둔 동안에도 영업 시간이 흐릅니다. 레시피 메뉴판·설정·관리·일지를 열거나 게임을 백그라운드로 보내면 영업 시간이 멈춥니다. 게임을 다시 열면 이어서 조리할 수 있습니다. 기존 버전의 매출, 업그레이드와 영업 기록도 이어집니다. 웹과 Android 앱은 각각 기기에 진행 상황을 저장합니다.

## Android 빌드

Android Studio에서 `android` 폴더를 열거나, JDK 17 이상과 Android SDK 35가 설치된 환경에서 실행합니다.

```powershell
cd android
.\gradlew.bat assembleDebug
```

설치용 테스트 APK는 `android/app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. 웹 소스와 이미지는 빌드 시 복사되므로 한 곳에서 수정할 수 있습니다. 앱은 게임 파일을 내장하여 오프라인에서도 실행됩니다.

## 구성

- `index.html`, `style.css` — 게임 화면과 반응형 배치
- `service.js` — 레시피, 손님 입장과 퇴장, 조리 순서, 판매와 정산, 이전 저장 데이터 변환
- `game.js` — 매장과 조리대 표시, 입력, 효과음과 자동 저장
- `assets/art/` — 매장 배경, 음식 9종, 손님 12종과 장비 3단계의 WebP 이미지
- `assets/` — Galmuri 글꼴과 배포 라이선스
- `android/` — 세로 화면 WebView 앱과 Gradle 빌드 프로젝트
